Silhueta, não pino. Um único path de carro visto de cima (~200 bytes) dentro do divIcon: ainda é HTML/CSS simples, e o carro girando no rumo diz "está andando" sem seta extra. A etiqueta separada, sobre fundo escuro, mantém o id legível em qualquer ângulo e sobre qualquer tile.
Selecionado. anel 2px --accent de 32px ao redor do carro com halo suave; etiqueta vira fundo --accent com texto branco. zIndexOffset 1000. O acento nunca preenche o carro — a cor do carro é sempre estado.
Offline. carro --v-offline com stroke tracejado --text-3, vidros apagados, etiqueta --text-2, opacity .85. Recua visualmente.
Rumo. o carro sempre aponta o heading, parado ou em movimento (um carro estacionado também tem orientação). Ícone só é recriado quando o rumo muda ≥10°.
Movimento. setLatLng a cada tick; setIcon só quando estado/seleção/rumo (arredondado a 10°) muda. Sem transição CSS de posição.
